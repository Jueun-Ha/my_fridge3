# My Fridge — 3주차

## 이번 주 기능
- 소비기한 D-day 계산 (`D-2`, `D-day`, `D+3`)
- 소비기한이 오늘부터 **3일 이하** 남으면 임박(오늘 포함)
- 소비기한이 지나면 경과로 표시
- 전체·임박·경과 식품 개수 표시
- 현황 버튼 클릭으로 해당 식품만 필터링
- 기존 등록/수정/삭제, 수량 조절, 정렬 및 장보기 기능 유지
- 간단한 모바일 화면 배치 보완

## 실행
`index.html`을 브라우저로 열고, '냉장고 열기' 버튼을 누릅니다.

## 주의
이번 주차는 `localStorage`를 사용하지 않으므로 새로고침하면 데이터가 초기화됩니다.
